## Overview

This project was completed as part of the **Big Data Analytics** module for the MSc Data Analytics programme.

The project analyses the Netflix Titles dataset using Python for data preprocessing, exploratory data analysis, visualisation, machine learning, and Apache Spark for distributed processing.

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- PySpark
- Google Colab

---

## Dataset

Netflix Titles Dataset

The dataset contains metadata describing movies and TV shows available on Netflix, including:

- Title
- Type
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genre
- Description

## Machine Learning

A Decision Tree Classifier was developed to classify Netflix content using metadata such as:

- Release Year
- Country
- Rating
- Duration
